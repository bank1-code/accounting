# تدقيق اتساق رموز ومعدلات ضريبة الأصناف

**تاريخ التدقيق:** 19 أغسطس 2026

## النطاق

يراجع التدقيق كل صنف يحتوي على `taxCodeId` ويرصد الحالات التالية: رمز ضريبة غير موجود، رمز غير نشط، أو اختلاف بين `products.taxRate` ومعدل الرمز في `tax_codes.rate`.

## النتيجة

نفذ الاستعلام على قاعدة البناء الحالية دون أي إدخال أو تعديل بيانات. كانت النتيجة **0 حالات عدم تطابق**. لذلك لم تنفذ مزامنة تصحيحية؛ ولا يوجد ما يستدعي تغييراً في البيانات الحالية.

## الضوابط المضافة

| الضابط | الأثر |
|---|---|
| اشتقاق معدل الصنف عند اختيار رمز ضريبي نشط | يمنع تخزين معدل يدوي مخالف للرمز عند الإنشاء. |
| مزامنة تعديل الصنف | تعديل معدل فقط لصنف مرتبط برمز يعيد استخدام معدل الرمز القائم. |
| تدقيق ومزامنة إدارية | يوفر النظام إجراء فحص ومزامنة محكومين بصلاحية إدارة كتالوج المخزون عند وجود بيانات مستقبلية. |

> لا توجد بيانات تشغيلية أو تجريبية في نطاق هذا التدقيق. يلزم إعادة الفحص قبل بدء التشغيل الفعلي وبعد كل استيراد أصناف أو رموز ضريبية.
