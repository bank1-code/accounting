# حزمة قبول UAT واعتماد زاتكا

**الغرض:** تجهيز مدخلات واعتمادات الاختبار قبل التنفيذ الفعلي، دون تخزين أي بيانات منشأة أو مفاتيح أو شهادات في المشروع.

## بوابة زاتكا الرسمية

توضح صفحة مطوري الأنظمة لدى الهيئة وجود **المتطلبات والمواصفات التقنية** وبوابة مطوري الفوترة الإلكترونية، وتربط ببيئة Sandbox الرسمية.[1] كما توضح الهيئة أن مرحلة التكامل تشمل متطلبات تقنية وتشغيلية وربط الحلول بأنظمتها، وتطبق على موجات محددة بعد إشعار المكلفين.[2]

| المدخل المطلوب | المالك المسؤول | لا يُسجل في الشيفرة |
|---|---|---|
| بيانات المنشأة الضريبية وVAT | المدير المالي / مفوض المنشأة | لا تحفظ داخل مستودع الشيفرة أو الاختبارات |
| بيانات بوابة المطورين وبيئة Sandbox | مفوض زاتكا | توضع عبر إدارة الأسرار فقط عند جاهزيتها |
| CSR والشهادة وCSID أو ما تتطلبه البيئة الرسمية | مفوض زاتكا / مسؤول التقنية | لا ترسل في المحادثة ولا تضاف إلى ملفات المشروع |
| قرار موجة التكامل وحالة الإلزام | مسؤول الامتثال الضريبي | يوثق مع تاريخ الاستحقاق قبل الإنتاج |

## نطاق UAT المطلوب

| الدورة | سيناريو القبول | دليل النجاح | المالك |
|---|---|---|---|
| إعداد المنشأة | شجرة الحسابات ومراكز التكلفة وخريطة POS | توقيع مدير مالي على الحسابات والاتجاهات | المالية |
| POS والنقد | بيع مختلط، مردود، فرق نقد، وإقفال جلسة | مطابقة النقد والبطاقات والقيد والمخزون يومياً | التشغيل والمالية |
| المشتريات والمخزون | طلب، أمر، فاتورة، دفعة وصلاحية واستلام | تطابق فاتورة المورد والمخزون وضريبة المدخلات | المشتريات والمخازن |
| الإنتاج | استهلاك مواد، منتج تام، هالك وتكلفة | تطابق الوصفة والاستهلاك والنتيجة المحاسبية | المطبخ / المعمل |
| الإقفال | سندات خزينة، توزيع مصاريف، قفل فترة | لا توجد مسودات أو مستندات معلقة، وميزان مراجعة متزن | المالية |
| زاتكا Sandbox | فاتورة مبسطة/قياسية بحسب الحالة، رفض وإعادة إرسال | استجابة البيئة الرسمية وسجل محاولة قابل للمراجعة | الامتثال والتقنية |
| التعافي | استعادة نسخة مشفرة على هدف مستقل | قياس مدة الاستعادة وعدد السجلات وتوقيع قبول | البنية التحتية |

## قرار التنفيذ

لا تُنفذ هذه الحزمة ولا تُنشأ بيانات تشغيلية بديلة حتى يوفر مالك المنشأة المدخلات الرسمية ويعتمد بدء UAT. عند ذلك تُجرى الاختبارات على بيئة معزولة أولاً، ثم تسجل الأدلة والنتائج الفعلية لقياس الجاهزية.
